# Drop and Pair 🎢

Curated pairings for theme park rides. Every ride gets a short gist and a set of things worth putting either side of it: a film, a record, a meal, a walk, or occasionally a hot bath.

It's a WordPress site, hosted on Pressable. This repo holds the plugin and the block theme in `wp-content/`, laid out the way they are on the server, and every push to `main` deploys them. The plugin's tests sit at the root, outside `wp-content/`, so they never deploy. See [`wp-content/README.md`](wp-content/README.md) for the local site, tests and deploys.
