# Drop and Pair

Curated pairings for theme park rides. Every ride gets a short gist and a set of things worth putting either side of it: a film, a record, a meal, a walk, or occasionally a hot bath.

It's a WordPress site, hosted on Pressable. This repo holds the plugin and the block theme in `wordpress/`, and every push to `main` deploys them. See [`wordpress/README.md`](wordpress/README.md) for the local site, tests and deploys.

It started out as a SvelteKit static site with its content in Markdown. That's all gone from here now, but it's still in the git history if I ever need it.
